# SNAPFIX

Lightweight mouse, display & crosshair utility for Windows.

## Features

- Mouse settings & optimization
- Raw Input polling analyzer
- Raw Accel curve editor
- Custom crosshair overlay
- Display controls
- Profiles & presets
- Diagnostics
- Backup & restore

## Requirements

- Windows 10 / 11 x64
- .NET 8 SDK+

## Build

```bash
dotnet restore
dotnet build -c Release
